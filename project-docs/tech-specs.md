# 技术规格

## 技术栈

- Next.js 16、React 19、Node.js 22
- MySQL 8、mysql2
- Sharp 图片处理
- Node.js Test Runner 与 Playwright
- Nginx 反向代理、systemd 服务管理

## 架构

- `app/`：页面、路由与 API。
- `components/`：前台和后台界面组件。
- `lib/`：数据库访问、业务规则、安全校验与服务集成。
- `data/`：经过审核的基础工具目录。
- `scripts/`：数据库初始化、迁移、后台任务和测试。

## 数据原则

- 草稿与发布快照相互隔离。
- 所有管理操作记录版本和审计信息。
- 外部网址必须使用安全协议并通过服务端校验。
- 密钥、凭据、数据库备份和用户上传文件不得提交到 Git。

## 编码要求

- 保持模块职责单一，复用公共校验和数据访问函数。
- 所有写操作必须进行权限、版本冲突和输入校验。
- 功能变更必须通过定向测试和生产构建。
